# 图片 → 像素画 → Minecraft投影 生成器

一条流水线完成：**任意图片 → 像素画 → Minecraft 建筑投影（.litematic）**。

- **阶段1（像素画）**：把图片缩放到指定像素尺寸（16×16 ~ 4096×4096 或自定义宽高，
  可选保持宽高比），每格 = 1 像素，**保留原图颜色，无任何色板限制**；可选去除背景
  （不规则裁剪、镂空效果）
- **阶段2（MC 投影）**：把像素画逐格匹配到最近的 Minecraft 方块颜色，生成
  **Litematica 建筑投影 .litematic** + 方块化预览图 + **材料清单 Excel**（中文方块名）

---

## 一、直接使用（推荐）

### 图形界面版

```bash
python main.py
```

1. **① 选择图片**（PNG / JPG / BMP / GIF / WebP）
2. 选择 **阶段1 像素尺寸**：
   - 预设 **16×16 ~ 4096×4096**（多比例）
   - 或选「自定义」输入宽高 1~4096
   - 勾选「**保持宽高比**」可避免拉伸（按较长边 = 目标尺寸自动算另一边）
3. 选择 **背景处理**：
   - `无`：不处理背景
   - `去除背景(镂空)`：主体外背景挖空（不规则裁剪，镂空图案）
   - `背景填玻璃`：**白色（或取样色）背景自动识别为整片玻璃，主体保持实体方块**
   - 可点击左侧图纸格子**取样背景色**（默认自动识别白色）
4. 点 **① 生成像素画**，左侧即时预览
5. 设置 **阶段2 MC 参数**（调色板 / 抖动 / 颜色空间 / 放大倍数 / 厚度 / 背面填充 /
   原点 / 名称 / 作者 / **朝向**），点 **② 生成MC投影**，右侧显示方块化预览
6. 也可直接点 **一键生成全部**，一步完成两个阶段
7. 输出文件在「输出目录」中（默认与图片同目录）：
   - `图片名.litematic` — **MC 建筑投影**（游戏内加载）
   - `图片名.preview.png` — 方块化预览图
   - `图片名.stats.xlsx` — **方块材料清单（Excel）**：中文方块名 + 数量 + 颜色，
     按用量降序排列并带色块预览，方便准备材料
8. `纯像素画PNG` 按钮可导出 1px/格 的中间像素画

### 命令行版

```bash
python cli.py 我的照片.png                       # 默认 48×48
python cli.py 我的照片.png --size 64              # 64×64
python cli.py 我的照片.png --size 128 --keep-aspect
python cli.py 我的照片.png --size 96 --mc-palette concrete --dither none
python cli.py 我的照片.png --size 64 --trim        # 去除白色背景（镂空）
python cli.py 我的照片.png --bg-glass              # 背景填玻璃：白底→玻璃，主体实体
python cli.py 我的照片.png --size 64 --bg-glass --bg-color 0188D3  # 蓝色背景填玻璃
python cli.py 我的照片.png --size 64 --scale 2 --thickness 2 --backing white_concrete
python cli.py 我的照片.png --size 64 --orientation floor   # 横放：地面/俯视
python cli.py 我的照片.png --size 128 --export-pixel-art
python cli.py 图1.png 图2.png 图3.png              # 批量转换
```

> 完整参数见 `python cli.py --help`。生成结果与图形界面完全一致。

## 二、在 Minecraft 中使用投影

1. 把 `.litematic` 文件放进 `.minecraft/schematics/` 文件夹
2. 进入游戏，按 `M` 打开 Litematica 菜单 → **投影 → 加载原理图**
3. 选中你的像素画投影，按 **放置/移动** 摆好位置
4. 手动对照建造；装了 **litematica-printer** 的话，按住打印机快捷键即可自动放置方块

> 默认 `--mc-data-version 3955`（1.21.1）；1.21.4 可用 `--mc-data-version 4085`。

## 三、参数说明

### 阶段1（像素画，保留原色）

| 参数 | 默认 | 说明 |
|---|---|---|
| 像素尺寸 | 48×48 | 16/24/32/48/64/96/128/256/512/1024/2048/4096 预设或自定义 1~4096 |
| 保持宽高比 | 关 | 按原图比例缩放（较长边=目标值），不拉伸 |
| **背景处理** | 无 | `无` / `trim`=去除背景(镂空) / `glass`=**背景填玻璃**（白色/取样色背景→整片玻璃，主体保持实体） |
| 背景色取样 | 自动白色 | 点击左侧图纸取样背景色（用于去除/填玻璃） |

> 像素画阶段只负责**尺寸**：图片颜色原样保留，不做任何色板量化，
> 因此没有颜色种类限制，照片的过渡色在阶段2 由 MC 调色板（156 种）匹配 + 抖动还原。

### 阶段2（MC 投影）

| 参数 | 默认 | 说明 |
|---|---|---|
| MC调色板 | auto（149种） | wool / concrete / terracotta / glass / wool+concrete / concrete+terracotta / misc |
| 抖动 dither | floyd | floyd=Floyd–Steinberg 抖动（渐变平滑）；none=纯最近色 |
| 颜色空间 | lab | lab=感知距离（推荐）；rgb=字面最近色 |
| 放大 scale | 1 | 每个像素放大为 N×N 个方块 |
| 厚度 thickness | 1 | z 方向层数，>1 即 3D 浮雕 |
| 背面填充 backing | 空 | 厚度>1 时背面方块（默认用前景方块填满），如 white_concrete |
| **朝向 orientation** | wall | **wall=竖放（墙面/平视）**：图像在 X-Y 平面，厚度沿 +Z 向外；
  **floor=横放（地面/俯视）**：图像在 X-Z 平面，厚度沿 +Y 向上 |
| 原点 X Y Z | 0 0 0 | 投影左下角（竖放）/ 最低层角（横放）世界坐标 |
| 玻璃去噪 | 开 | 消除孤立玻璃/实体噪点，让玻璃只出现在成片区域（`--no-glass-cleanup` 关闭） |
| 名称/作者 | 像素画/空 | 投影元信息 |

## 四、特性与技巧

- **背景填玻璃**：选择「背景填玻璃」后，程序自动识别与图片边缘相连的白色（或取样色）
  背景区域，把该区域整片替换为最接近的玻璃方块（白底 → 白色玻璃），主体图案保持
  实体方块不变——适合做"玻璃衬底"的挂画/摆件。识别逻辑与「去除背景」相同：
  主体内部不与边缘相连的同色区域不会被误判为背景
- **透明像素 = 空气**：「去除背景(镂空)」模式挖掉的格子不会生成方块，形成镂空图案
  （适合做不规则形状、挂画剪影等）
- **图像顶部 = 建筑最高层**：图片第 0 行放在最高 y（竖放）或最大 z（横放），正着看就是
  "挂在墙上的画" / "铺在地面的画"
- **为什么纯红色变成了橙色**：默认用 CIE Lab 感知距离，人眼觉得纯红 #FF0000 更接近
  橙色羊毛；想要“字面最接近”把颜色空间切到 **rgb**
- **自动剔除不稳定方块**：以下 7 种方块不会出现在任何调色板中，避免破坏作品完整性——
  冰 `ice`（光照会融化）与浮冰 `packed_ice`（半透明）、雪层 `snow` 与灵魂沙 `soul_sand`
  （非完整方块）、基岩 `bedrock`（生存无法获取）、黏液块/蜂蜜块（透明黏性）。
  **已保留**：蓝冰 `blue_ice`（不会融化，提供蓝色系选择）、沙子/红沙/沙砾/混凝土粉末
  （受重力方块，贴在墙面/地面上放置没有问题）。发光方块（萤石/海晶灯/蛙明灯等）
  保留作发光点缀；想继续剔除可编辑 `mc_palette.py` 中的 `UNSTABLE_BLOCKS`
- **玻璃一致性（双重保护）**：
  1. **匹配门槛**：只有玻璃比最佳实体方块**明显更接近**（距离 < 实体×0.75 且绝对差距 > 阈值）
     时才允许选用玻璃——白色/近白区域会优先匹配雪块/羊毛/混凝土等实体，不会因为
     "白色玻璃恰好是纯白"而在大块白色图案中间出现散点玻璃
  2. **连通域去噪**：面积 ≤10 格的玻璃小块（嵌在实体中）整体换成周围实体、
     玻璃海里的小块实体会补成玻璃；成片大区域保留（如纯黄 → 整片黄色玻璃）
  3. 可整体关闭：`--no-glass-cleanup`
- **调色板建议**：大色块用 `concrete`（颜色最纯）；需要渐变色用 `auto`；木质/中世纪用
  `misc`；玻璃做发光/描边用 `glass`
- **大图提示**：1024×1024 以上生成需要几十秒（4096×4096 约 6~15 秒），状态栏有进度；
  超大图预览自动用 1px/格显示
- **性能**：MC 颜色匹配用 numpy 向量化加速，百万级像素也只需数秒

## 五、从源码运行

环境要求：Python 3.9+（推荐 3.10+），Windows。

```bash
pip install -r requirements.txt
python main.py            # 图形界面
python cli.py 图片.png    # 命令行
```

## 七、格式兼容性

生成的 `.litematic` 为 **Version 7 / SubVersion 1**，`BlockStates` LSB 优先、
`bits=max(2, ceil(log2(palette)))` 64 位打包，索引 `index = y*(W*Z) + z*W + x`。
已通过 litemapy（独立实现）逐方块交叉验证与内置 NBT 读取器回环解析。
